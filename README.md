# primarygoals.org — static site

The Primary Goals site (leadership, teams and organizational development), rebuilt from WordPress as plain static files.
No database, no PHP, no plugins, no logins, and no passwords or API keys anywhere in this repository.

## What is where

| Folder / file | What it is |
|---|---|
| `public/` | The finished website. This is the folder the host serves. |
| `content/pages/` | The pages as HTML with a JSON front matter block (`<id>-<slug>.html`). |
| `content/posts/` | The blog posts, same format (`<slug>.html`). |
| `content/site.json` | Site title, tagline and URL. The top menu is set in `tools/extract_wordpress.py` (`NAV`). |
| `content/sidebars.json` | The side-panel menus (Books, Models, Group Dynamics, ...) and which pages show them, captured once from the live site. Edit it to change a panel. |
| `content/skipped.txt` | Everything from the export that was left out, and why. |
| `static/` | Files copied into the site unchanged: `wp-content/uploads/` (images, PDFs used by pages), `Diagrams/`, `Readings/`, `assets/site.css`. |
| `build.py` | Generates `public/` from `content/` and `static/`. Python 3.8+, standard library only. |
| `tools/check_site.py` | Checks every internal link, image and stylesheet reference in `public/`. |
| `tools/extract_wordpress.py`, `tools/extract_assets.py` | One-time importers that produced `content/` and `static/` from the WordPress export and the site archive. |

## Everyday tasks

Rebuild after any change, then check it:

    python3 build.py
    python3 tools/check_site.py

**Edit a page or post:** change the text in `content/pages/…` or `content/posts/…` (below the `---` block), rebuild, commit, push.
**Change the design:** edit `static/assets/site.css`, then rebuild.

## Notes

* URLs are the same as on the WordPress site. `/blog/` and `/site-map/` are generated by `build.py`.
* Only the uploads the pages actually use were copied (about 185 of ~3,700). The rest are still in the original archive, which is not in this repository.
* Left out on purpose (see `content/skipped.txt`): drafts, private and password-protected pages, and pages that only work inside WordPress (shop, cart, checkout, My Account, login, members-only content, the Gravity Form page).
* Side panels: 191 pages show the same section menu as the live site (e.g. the Books list on every `/teams/books/` page). The live site's "Blog categories" panel is left out because there are no category pages here.
* Google Tag Manager (`GTM-KHMRKD2`, set in `build.py`) is on every page and manages the other tags. Every content page also carries titles, descriptions, Open Graph/Twitter tags and JSON-LD like the live site had.
* Videos on the two `/offers/brandscripts-made-simple/…` pages are listed in `VIDEOS` in `tools/extract_wordpress.py` (the export did not contain them).
* The original page layouts were built with Thrive Architect. They are rendered here as plain content in one simple design, so layout and styling differ from the old site.
* `tools/check_site.py` reports no broken internal links. Links to the retired short addresses (`/bmsu/`, `/discovery/`, `/schedule`, `/login` and similar) and to `/marketing/` were removed (the link text stays). Three uploads (`2000Ideavirus.pdf`, `courses-box.png`, `live-workshop.jpg`) are not in the archive.
* The raw export and archive are never committed (`.gitignore`): they contain account details.
